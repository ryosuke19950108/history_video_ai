# TREATMENT — 箸墓古墳は誰の墓か（テスト版, 59.6 s）

Style: my-styles/lamplit-archive (draft, technique base Visual Investigation). Test of the whole pipeline: script → VOICEVOX → timeline → picture → mix → master.

## Three candidate structures
1. **A question narrowed** — place → the mound → the legend → "who?" → two answers → the size in the source → the dates → still unknown. *Chosen*: one finding per sentence, a clear turn (the question), an open ending fitting a mystery channel.
2. **Cold open on the legend** — start on "日は人作り、夜は神作る", then reveal the real mound. Strong hook, but the test needs the map-to-site move first.
3. **Two columns from the start** — 治定 vs 卑弥呼説 throughout. Too static for the short form.

## Logline and arc
A 280-metre tomb at the foot of the Nara basin has an official occupant and a famous rival claim; the sources and the dates narrow it, but do not close it.
Setup (map, mound, legend) → turn (the question after a near-silence) → two theories, the source meets the measurement, the dates → open ending (pull out, the forest).

## Benchmark
Learn from museum-gallery documentaries and archive-based history channels: dark ground, sources shown as objects, serif headings, always-on subtitles, sources named. Not taken: any channel's name, logo, title wording, set phrases, thumbnails, voice.
