# お手本の数値化（手順書 第2部）

- 対象：参考チャンネルの本編フレーム 51 枚（17 本 × 再生位置 約 25 / 50 / 75 %）。サムネイルは除外。動画本体・ストーリーボードは取得できなかったため、動き（カット頻度・ズーム）は未測定。
- 測定：`python tools/measure_style.py <frames_dir>` → `config/style_measurements.json`（フレーム画像はリポジトリに入れない）
- 条件化：`config/style.json` の `conditions`（手順書 5-4）。判定：`python tools/check_style.py <stills_dir> --film <film_dir>`

| 測ったもの | 結果 | 条件にすると |
|---|---|---|
| 平均輝度 | 34.5 / 255（中央値 25.5） | 平均輝度 45 以下 |
| 暗いコマ（<50） | 82.4 % | — |
| 明るいコマ（≥90） | 2.0 % | 5 % まで |
| 非常に明るいコマ（≥150） | 0 % | 0 % |
| 色の乗った画素 | 15.2 % | 5〜30 % |
| 暖色 / 寒色（色の乗った画素中） | 55 % / 42 % | 暖色 ≥ 寒色 |
| 周辺減光（中央/縁の輝度比） | 2.68 | 1.8〜4.0 |

テスト版（`films/hashihaka-test`）の実測（1 秒ごと 60 コマ）：平均輝度 27.1、明るいコマ 0 %、色の乗った画素 9.7 %、周辺減光 1.88、暖色/寒色 29.7 — すべて条件内。ただし寒色はお手本（42 %）より大幅に少ない。
